## 持久化修复

1. 扩大候选初筛对工业检测、制造、质检及三维基准的覆盖；摘要未命中范围词仍进入模型判断。
2. 不确定论文由 DeepSeek 提出疑点，搜索并读取公开摘要、HTML 正文、项目页和仓库 README，再进行判断。搜索片段不能直接作为收录依据；不下载 PDF。
3. 引用通过资料编号绑定实际 URL，丢弃无法匹配的引用；由程序截取前后各最多 240 字符的原文，校验工业场景、视觉模态和缺陷任务。模型仍负责语义判断。
4. 区分已完成工业实验与潜在工业用途；同时含医学实验不排除；没有数据集专名本身不构成排除理由。
5. 提高每轮额度至 400 次模型判断、60 篇调查、每来源 40 次详情刷新；优先处理有线索或已有证据的候选。
6. 网络请求有有限重试；单篇暂时失败继续处理其他论文，连续四篇失败才中断；密钥、权限、余额错误立即停止。无效结构带具体错误重试，调查成果不会因最终判断失败而丢弃。
7. 保留失败状态、采集进度和逐篇调查记录；支持只复核存量候选，避免反复扫描目录。每周一北京时间 09:23 的任务仍执行完整链路。

## 尚未解决的限制

Unified Anomaly Detection via Multi-Scale Contrasted Memory 仍为 pending。前次独立验收依据出版摘要中的空间偏差图与工业检测评测描述，将其计入相关参考集；本次 DeepSeek 尽管取得同一摘要，仍要求具体工业数据集或实验设置，暴露了模型执行范围标准时偏保守的问题。其公开搜索主要返回出版页导航，未提供更强证据。没有为凑齐回归数而手工改成 accepted。

其余待核实记录及原因见结构化报告。它们会进入后续定时复核，但不能保证每周都能找到新公开证据。当前支持的来源域名、网页标题匹配、目录关键词和搜索排名仍可能造成遗漏；引用真实也不保证模型解释和中文概括完全准确。

中间运行曾遭遇 arXiv HTTP 错误、DeepSeek HTTP 500、搜索长度限制和输出格式问题，均保留了结果及失败标记。最后这次完整运行通过，不代表外部接口今后不会再出现故障。
